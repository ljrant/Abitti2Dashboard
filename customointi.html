Koulukohtaiset muutokset

Kaikkia koulukohtaisia asetuksia ei tarvitse muuttaa lähdekoodista. Osaa voi muokata myös suoraan ohjelman Asetukset- tai Yhteydet-välilehdellä. Lähdekoodin oletuksia tarvitaan lähinnä silloin, kun sama valmis ohjelmapaketti jaetaan usealle saman lukion käyttäjälle tai koneelle ja haluat, että oikeat asetukset ovat valmiina ilman että jokaisen tarvitsee säätää niitä itse.

Ennen ajamista: tarkista lataamasi lähdekoodi. Katso lähdekoodin tarkistusohje.

Missä asetukset ovat?

Avaa src/Program.Core.cs ja etsi [KOULU][ASETUKSET]. KTP-kohtaiset oletussalasanat löytyvät kohdasta [KOULU][OLETUSSALASANAT].

Muuta yleensä vain lainausmerkkien sisällä olevia arvoja. Tallenna tiedosto ja rakenna EXE uudelleen komennolla Rakenna_ja_kaynnista.cmd.

Muokattava asetuslohko

const string Username = "valvoja"; // [KOULU][ASETUKSET] const string KtpDomainSuffix = ".1068.koe.abitti.net"; const string StudentServerSuffix = ".1068"; const string ReservationUrl = "https://example.invalid/palvelinvaraus"; const string PasswordFileUrl = "https://example.invalid/valvojan-salasanat"; const string StudentWifi = "espoo_koeverkko1"; const string StudentUsername = @".\Abitti"; const string StudentPassword = "OpiskeluKoe-26#"; const string DefaultDecryptPassword = "VAIHDA_OLETUS_PURKUKOODI_TÄHÄN"; // [KOULU][OLETUSSALASANAT] KTP1 → KTP10 static readonly string[] DefaultPasswords = { "", "", "", "", "", "", "", "", "", "" };

Mitä asetukset tekevät?

AsetusVaikutus
KtpDomainSuffixKTP1–KTP10:n oikeat verkko-osoitteet.
StudentServerSuffixOpiskelijan ohjeessa näkyvän palvelinosoitteen loppuosa.
ReservationUrlPalvelinvarauksen linkki.
PasswordFileUrlValvoja-salasanojen linkki.
StudentWifiOpiskelijan ohjeessa näkyvä koeverkon nimi.
StudentUsernameOpiskelijan Windows-käyttäjätunnus.
StudentPasswordOpiskelijan Windows-salasana.
DefaultDecryptPasswordTuo koe -ikkunan oletuspurkukoodi.
DefaultPasswordsKTP1–KTP10:n valvoja-salasanojen oletukset järjestyksessä.

Mikä vaatii uuden buildin?

Lähdekoodiin tehty muutos: kyllä, rakenna EXE uudelleen.

Yhteydet-välilehdellä vaihdettu KTP-salasana: ei, se tallennetaan käyttäjäkohtaisesti tälle koneelle.

Asetukset-välilehdellä muutettu kirjautumisohje tai linkki: ei paikallisesti, mutta jos haluat jakaa muutoksen muille koneille, tee sama muutos lähdekoodiin ja rakenna EXE uudelleen.

Nopea etenemisjärjestys

1
Muuta KTP-domain ja opiskelijalle näytettävä palvelinosoite.
2
Muuta WiFi, opiskelijan tunnus/salasana ja koulun linkit.
3
Lisää halutut KTP-oletussalasanat.
4
Tallenna ja aja Rakenna_ja_kaynnista.cmd.
5
Tarkista ohjelmasta Yhteydet ja opiskelijan kirjautumisohje.
